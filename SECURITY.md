# Security Policy

## Supported Versions

Only the latest released version of cscs-key receives security updates.
Please upgrade to the latest release before reporting.

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub's **Report a
vulnerability** button in the
[Security tab](https://github.com/eth-cscs/cscs-key/security/advisories/new).
Do not open a public issue for security problems.
